## 10. Cross-project lessons (이번 세션)

| Lesson | 적용 |
|---|---|
| **directive → multi-reviewer 역효과 검출** | funding 빼기·CV 참고를 충실 실행했으나 페르소나+critic이 역효과 수렴. 혼자면 박제됐을 텍스트를 교정. anti-sycophancy 실전. |
| **인포그래픽 영어 라벨 = 구조 변경** | 텍스트 제거+negative로 안 되면 다이어그램 구조 자체를 바꿈(허브-스포크→수직카드). `feedback_infographics_visual_first_regeneration` 보강. |
| **generate_image.py idempotent** | 출력 존재 시 skip. 재생성 전 `rm` 필수. mtime으로 검증. |
| **Notion replace_content 부제 병합** | 본문 첫 문장을 부제 blockquote에 병합하는 반복 버그. 부분 update_content는 모호 매칭 위험. |
| **bounded honesty** | "숫자 0 공개"도 "과장"도 아닌 중간 — 월 stipend는 공개, in-kind/미확정은 정성적. |
