## 사전 결정 (PI 직접 확정 필요)

피드백 라운드 시작 전 PI가 결정할 것:

1. **피드백 대상 대학원생 명단** (권고: 학부생 모집 직접 관련자 1–2명 + lab PhD/석사 students 2–3명, 총 3–5명)
2. **피드백 채널** — 아래 옵션 중 선택
3. **피드백 마감** — 권고: 메시지 발송 후 **3 영업일 이내**

### 채널 옵션

| 채널 | 장점 | 단점 | 권고 |
|---|---|---|---|
| **(A) Notion 페이지** | 본문 + 댓글, 비기술 인원 익숙 | 외부 노출 시 권한 관리 | snuconnectome workspace 활용 — **권고 1순위** |
| **(B) Slack DM (lab 채널)** | 즉시성, 응답률 ↑ | 변경 이력 추적 어려움 | NeuroX Slack 활용 — **권고 2순위 (병행)** |

편한 응답은 Slack 또는 Notion comment 중 선택.

## 피드백 요청 메시지 template

### 버전 1 — Slack DM / 이메일용 (짧은 호소)

```
[학부생 펠로우십 광고문 review 요청]

안녕하세요 ○○님,

학부생 연구 펠로우십 광고문 초안이 나와서 review 부탁드립니다.

링크: [Notion 페이지 URL]
또는 첨부: docs/RECRUITMENT_POSTING.md

분량: 한 페이지 반 정도, 5–7분 읽기.

다음 7가지 관점에서 떠오르는 게 있으면 자유롭게 적어 주시면 됩니다:

1. 학부생이 1회 읽고 핵심 6개(자격/제출/혜택/일정/선발기준/문의)를 파악 가능한가
2. "지원해보고 싶다"고 느끼게 하는 호소력이 있는가
3. 에세이 요건(메인 600–900자 + 보조 300–500자)이 학부생에게 과한가/부족한가
4. 선발 자질 세 가지(꿈/호기심/유연성)가 학생에게 무슨 뜻인지 추측 가능한가
5. "GPA/추천서/영어 안 받음" 명시가 오히려 의심을 일으키지는 않는가
6. 학생이 30초 안에 "내가 적합한지" 판단할 수 있는가
7. 빠진 정보, 잘못된 표현, 오해 소지가 있는 부분

마감: ○○월 ○○일 (○요일) 저녁까지.

광고는 학과 게시판 / SNS / 이메일링으로 곧 배포할 예정이라 빨리 짚어 주시면 큰 도움이 됩니다.

— 차지욱 드림
```

## 받은 피드백 → 광고문 v3 통합 워크플로우

1. **수렴 단계** (마감 직후 1일): 받은 피드백을 항목별로 정리. 동일 지적 2명 이상 = 강한 신호.
2. **분류**: 사소한 표현 수정 / 구조 변경 / 정보 추가 / 정보 제거 / 톤 조정
3. **차교수 PI 최종 결정**: 어떤 피드백을 v3에 반영할지. 모든 피드백 반영 의무 없음.
4. **v3 작성**: `docs/RECRUITMENT_POSTING.md` 직접 수정 (git diff로 변경 추적)
5. **게시 결정**: v3 통과 시 외부 배포 (학과 게시판 / SNS / 이메일링)

### 2. 일정 표 (전면 재구성)
- v1: 마감 2026-08-31 / 면접 9/1-9/15 / 시작 2027-03-02 (6개월 갭)
- v2: **마감 2026년 6월 말 (잠정) / 면접 7월 초~중순 / 합류 7월말~8월** (여름 방학 합류로 갭 제거)
